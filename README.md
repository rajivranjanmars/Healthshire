# Healthshire

Static wellness website with physical, mental, and social well-being pages, exercise content, and nutrition information. Built with HTML, CSS, and JavaScript.

## Getting started

Run `python -m http.server 8000` here and open `http://localhost:8000/`. The landing page links to `physical.html`, `social/index.html`, and `fitness website/mental.html`.
